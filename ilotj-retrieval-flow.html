How ILOTJ retrieves a guideline

A guideline is never handed to an agent in full — it's retrieved per query, ranked by a blended score, then optionally topped up with defaults. This page walks through setup and the retrieval mechanism itself, so a query's path to "here's the instruction" is traceable end to end.

Setup

Connecting a guideline to your tool

Five steps, done once per tool integration — upgrade, wire the endpoint, then verify against a real query.

1

Upgrade the library

llm-studio-integrations ≥ 1.45.2 in your agent.

2

Update the agent

Push the new version in Agent Genie / LLM Studio.

3

Toggle Guidelines

Open the VertexAI / OpenAI / Anthropic integration and enable Guidelines under Agent Genie Mode.

4

Set the retrieval URL

Paste the ILOTJ endpoint into Guideline Retrieval URL. Mapping ID, Scope ID, Tier ID stay blank — the UI supplies those.

5

Verify in the trace

Run a query, then confirm the extracted search string and fetched instructions in the tool's trace.

Mechanism

From query to ranked guidance

A query is searched against three independent spaces, merged, scored on three signals, filtered by threshold, ranked — then defaults are appended without competing for the ranked slots.

Weights & thresholds

The four config blocks that shape retrieval, with their default values.

overall_weights — how the context score is built

ParameterDefaultMeaning
semantic_similarity_weight0.60Weight on embedding-based match. Higher favors meaning over exact wording.
keyword_score_weight0.15Weight on n-gram keyword match. Higher rewards exact textual overlap.
document_score_weight0.25Weight on document coverage — credit for matching in more than one space.

overall_retrieval — final filtering & ranking

ParameterDefaultMeaning
final_retrieval_limit10Max ranked results returned, before default variants are appended.
max_keyword_score_cap3Ceiling on keyword score, so repeated matches can't dominate ranking.
context_score_threshold0.70Minimum context score to survive filtering.
include_default_without_searchtrueAllows default variants into the response without an explicit search match.
enforce_default_without_searchtrueForces eligible defaults in, still checked against their own when_not_to_apply.

Per-space scoring — Description, When To Apply, When Not To Apply

ParameterDescriptionWhen To ApplyWhen Not To Apply
retrieval_limits1075
similarity_score_threshold0.700.680.85
keyword_score_threshold0.250.200.50

When Not To Apply is held to a stricter similarity bar (0.85) because a match there suppresses the variant — a loose match would wrongly exclude relevant guidance.

Tuning cheatsheet

What to move when retrieval is under- or over-firing.

GoalChange
Improve semantic recallLower similarity_score_threshold values
Increase precisionRaise similarity_score_threshold values
Favor exact wording matchesIncrease keyword_score_weight
Favor meaning-based matchingIncrease semantic_similarity_weight
Reduce noisy resultsIncrease context_score_threshold
Return more candidatesIncrease retrieval_limits and final_retrieval_limit
Reduce influence of repeated keywordsLower max_keyword_score_cap
Always include baseline guidanceEnable enforce_default_without_search

Watch out for

Getting it right

Three details that are easy to get wrong on first setup.

Search string regex

Populate carefully

The Guideline Retrieval Search String Regex Key runs against the incoming user query. Whatever it extracts is what retrieval searches on — get it wrong and every downstream score is scored against the wrong text.

Access

Share ≠ LMS access

Using a guideline for retrieval requires LMS or Global scope access. The page's Share feature only grants ILKB access — LMS access has to be granted separately via Access Management.

Citations

Anchor is the default

IL Guideline Citation Markdown Prompt and Anchor Prompt control how a cited learning is rendered. Anchor-type citations are recommended for consistency across products; both are configurable.
